### Selected work

#### [secure-code-review-cases](https://github.com/BeeDay7/secure-code-review-cases)
Fourteen secure-code-review cases in Python and JavaScript (SQL injection, SSRF, IDOR, deserialisation, prototype pollution, XSS and more). Each case pairs vulnerable and fixed code with its CWE and OWASP category, and 39 automated tests run in GitHub Actions.

#### [qa-automation-portfolio](https://github.com/BeeDay7/qa-automation-portfolio)
A test-automation suite for a FastAPI application: UI tests (Selenium), API contract tests against the OpenAPI schema, and security-control tests, organised in Robot Framework and run in one CI pipeline, with design and limitations documented.

#### [OIBSIP: cybersecurity internship](https://github.com/BeeDay7/OIBSIP)
Network reconnaissance with Nmap, a network-threats report and a social-engineering assessment report.

A FastAPI agent that routes natural-language requests to controlled tools (SQL analytics and a churn-prediction model), with tests and interactive API documentation.
